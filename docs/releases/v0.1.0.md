# OwnPI v0.1.0

First stable release, replacing the earlier v0.1.0 Beta assets.

- Source snapshot: `c4cb205012c2ba0824ea5420312bf9906e0cc921`.
- Platforms: macOS Apple Silicon (`darwin-arm64`) and Linux x86_64.
- Base includes the CLI (`ownpi`) and native terminal interface (`ownpi-tui`).
- Task Level supports interactive Direct sessions; Research Level runs the staged research workflow.
- The optional Neuroscience Pack supplies Brainlib, neuroscience skills, and external knowledge.
- Includes reviewed user-facing answers, a session resume picker, and the latest TUI rendering fixes.

## Install or upgrade

New installations use the unchanged command:

```sh
curl -fsSL https://raw.githubusercontent.com/yzz673/OwnPI/main/install.sh | bash
```

Existing installations, including the earlier v0.1.0 Beta, can run:

```sh
ownpi update
ownpi pack update neuroscience  # only if this optional Pack is installed
```

The version remains 0.1.0, so old installations may not advertise an available
update. Run the command explicitly; the installer detects changed artifact
digests. Do not uninstall or delete your app home. Stop active work before
updating, then restart the CLI or TUI. Installation preserves configuration and
session storage; preservation does not guarantee that every old in-flight run
can resume across runtime changes.

Run `ownpi-tui` for the terminal interface or `ownpi --help` for CLI commands.
Use a dedicated workspace and choose permissions appropriate to the task.

Archives, SHA-256 checksums, manifests, and validation reports are attached to
the GitHub Release. Beta-only restrictions in older user documentation do not
describe this release. Third-party components retain their own licenses;
consult the notices and licenses included in the packages.

## Known installation limitation

For the Neuroscience Pack on Linux, use an app-home path without spaces or shell
quotes (the default `~/.ownpi` normally satisfies this). Brainlib entrypoints
fail in the tested custom path containing spaces and a single quote. Base CLI
and TUI installation and operation passed in that path.
