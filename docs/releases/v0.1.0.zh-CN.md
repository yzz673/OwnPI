# OwnPI v0.1.0

OwnPI 的首个 stable 版本。

- 源码快照：`c4cb205012c2ba0824ea5420312bf9906e0cc921`。
- 平台：macOS Apple Silicon（`darwin-arm64`）和 Linux x86_64。
- Base 包含 CLI（`ownpi`）和原生终端界面（`ownpi-tui`）。
- Task Level 支持交互式 Direct 会话；Research Level 执行分阶段研究工作流。
- 可选 Neuroscience Pack 提供 Brainlib、神经科学技能和 external knowledge。
- 包含经过评审的用户回答、会话恢复选择器，以及最新 TUI 渲染修复。

## 安装或升级

新安装仍使用以下命令：

```sh
curl -fsSL https://raw.githubusercontent.com/yzz673/OwnPI/main/install.sh | bash
```

已有安装可运行：

```sh
ownpi update
ownpi pack update neuroscience  # 仅在已安装此可选 Pack 时运行
```

版本号仍为 0.1.0，因此旧安装可能不提示可用更新。请显式运行更新命令；安装器会检测产物摘要的变化。不要卸载或删除应用目录。更新前停止活动工作，更新后重新启动 CLI 或 TUI。安装会保留配置和会话存储，但保留数据不保证所有旧版未完成 run 都能跨运行时变更恢复。

运行 `ownpi-tui` 使用终端界面，或用 `ownpi --help` 查看 CLI 命令。请使用专用工作区，并选择适合任务的权限。

GitHub Release 附有安装归档、SHA-256 校验文件、清单和验证报告。第三方组件保留各自许可，请查阅包内声明和许可证。

## 源码

Stable 源码包含在本仓库的 [source/](../../source/README.zh-CN.md) 中。克隆产品仓库并进入 `source/`，即可查看源码，或在自行准备依赖后运行。`SOURCE_MANIFEST.json` 标识准确的源码提交和文件摘要。源码快照使用其自身的 LICENSE 和 THIRD_PARTY_NOTICES.md，不会重新授权其他产品材料。Release 附件包含可安装产品及其元数据，不提供独立源码归档。产品根 README 介绍产品使用，源码 README 介绍代码与依赖准备。

## 已知安装限制

在 Linux 上使用 Neuroscience Pack 时，应用目录路径不要包含空格或 shell 引号（默认的 `~/.ownpi` 通常满足要求）。在测试中，包含空格和单引号的自定义路径会导致 Brainlib 入口失败。Base CLI 和 TUI 在该路径下的安装与运行验证通过。
