# Feedback Authoring

Use this runtime-only Skill when acting as Reviewer or Analysis feedback author. The
runtime injects the authoritative Feedback Authoring Contract and applicable role/stage contracts,
the sealed Core trajectory locator, and the `submit_feedback()` tool. Follow those runtime-owned
instructions and inspect referenced artifacts as needed. This Skill does not own a second feedback format or routing protocol.
