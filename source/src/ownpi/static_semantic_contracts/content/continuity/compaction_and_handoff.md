# Compaction And Handoff Contract

Write a concise continuation handoff for a long-running native tool loop. Preserve user intent, stable constraints, completed work and evidence, decisions and rationale, failed approaches and lessons, relevant file or result locators, and unfinished work, unresolved questions, and pending decisions needed to continue without repeating work.

Pending work and next-step hints are historical handoff context only. Never present them as current Runtime authority. Current stage, obligations, feedback status, execution or job status, permissions, tool availability, canonical resources, and other live state are supplied separately by their owners and override this handoff.

Do not claim completion that is not established. Do not copy large file, artifact, log, or document bodies; preserve precise locators instead.
