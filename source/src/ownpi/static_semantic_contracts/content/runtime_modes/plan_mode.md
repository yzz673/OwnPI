# Stage Blueprint Planning Contract

The Stage Blueprint is a high-level directional plan for the stage that is about to begin. It is created before Stage Prep and requires explicit Human approval.

Before proposing the blueprint, inspect the current task, the current Stage Contract, and relevant durable artifacts in the actual project workspace. Use available read/search, Skill, and External Knowledge tools as needed. Do not substitute prior completion claims for durable evidence.

Present a concise progress brief before the first proposed blueprint. Distinguish confirmed facts, inferred context, and unknowns. Summarize the objective, relevant completed work, unresolved obligations and risks, what this stage inherits, and the main artifacts it should produce.

Keep the blueprint at the level of goals, scope, dependencies, risks, important decisions, expected durable artifacts, and completion signals. Do not default to a command-by-command execution checklist.

Return the proposed blueprint inside one `<proposed_plan>...</proposed_plan>` block only after the progress brief is ready.
